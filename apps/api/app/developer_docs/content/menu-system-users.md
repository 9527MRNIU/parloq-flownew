## 页面用途

用户管理用于创建能够登录 Parloq 管理端的用户名 / 密码账号，并把用户分配到一个角色。该页面只对管理员开放。

## 用户字段

- 用户名和显示名称；
- 所属角色；
- 管理员或普通账号类型；
- 启用 / 停用状态；
- 最近登录时间；
- 创建时间。

## 可执行操作

- 创建用户并设置初始密码；
- 编辑用户显示信息和所属角色；
- 编辑时留空密码表示保持原密码；
- 为停用用户重新启用登录；
- 停用不再允许登录的用户。

## 权限生效方式

普通用户从所属角色获得菜单和操作权限。修改角色后，下次接口请求会按新角色判断；导航也会在重新加载后反映新的菜单范围。

## 功能边界

- 用户只能属于一个角色；
- 停用用户会阻止继续使用管理端，但不会删除其创建的业务数据；
- 页面不展示密码原文，也不能读取已有密码；
- 用户管理不负责配置角色的具体权限，应进入[角色管理](/system/roles)。
