## 页面用途

协议管理维护共享 Baileys 网关上的逻辑协议节点，以及用于渠道回退的协议池。节点决定新账号能否接入、账号能否参与营销、容量上限和绑定后的资料同步范围。

## 节点开关

- **进号开关**：关闭后停止新账号通过该节点接入，不影响已在线账号；
- **营销开关**：关闭后节点内账号不再被营销任务选择，连接状态不受影响；
- **批量上线 / 下线**：对选中节点统一调整在线运行状态。

## 容量与连接策略

节点可以设置账号总量、在线账号和并发配对上限。留空表示该项不限制。

账号绑定限速中的“渠道新建速率”按统计窗口累计单个渠道创建的新配对任务数，用于拦截短时间突发请求，默认留空表示不限制；“并发配对上限”统计协议节点此刻仍在进行的任务数，用于保护节点容量，两者不是同一个限制。

连接模式支持“按需在线”和“持续连接”。按需在线会在配对同步、发送或人工操作期间持有连接，空闲后只断开 Socket，不会退出账号登录。还可以配置空闲断开秒数和验证后保活时间。

## 资料同步范围

基础身份始终同步。可选范围包括头像、资料状态、商业资料、群组概览 / 详情、联系人、聊天列表、消息历史、隐私设置和黑名单。接入开始时会保存同步策略快照，之后修改不会改变进行中的接入。

## 协议池

协议池保存有顺序的节点列表。渠道发起新接入时选择第一个当前可接入且未超容量的成员；如果没有可用成员，请求会明确失败，不会绕过配置使用其他节点。

## 功能边界

- 协议节点是逻辑运营分区，不是独立控制面账号；
- 修改或关闭节点不会自动迁移历史账号；
- 被账号、渠道或协议池引用的节点不能归档；
- “接口规范”展示渠道级公共配对契约，模板不得写死节点 ID。
