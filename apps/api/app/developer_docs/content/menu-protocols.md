## 页面用途

协议管理维护可以被节点引用的协议定义。每条协议由实现仓库、软件包、具体版本、适配器和构建状态共同确定；同一仓库的不同版本是不同协议，可以并行保留和测试。

## 版本信息

“当前版本”是项目已归档并构建的实现版本；“远程版本”来自该软件包的上游注册表，只展示与当前协议相同类型的最新版本。稳定协议对比最新稳定版，RC、Beta、Alpha 等预发布协议对比最新预览版。远程检查只用于发现版本，不会直接替换正在运行的协议。

新建协议时先选择版本类型，再从该类型的远程版本中选择具体版本。版本类型只用于筛选，不作为独立字段保存。

新建协议后会自动进入构建队列。平台按所选精确版本下载 NPM 归档，校验上游完整性，禁用安装脚本，并执行适配契约与模块加载测试；成功后生成独立运行包并转为“构建完成”，无需人工进入服务器构建。失败或需要平台适配时会保留具体状态，可在操作列重新构建。

## 功能边界

- 协议定义不保存容量、限速和营销开关，这些属于节点；
- 已有协议不会被远程版本原地覆盖；
- 每个账号在首次进入网关时永久绑定节点所选的协议和版本；新增协议、构建新版本或调整路由不会改变现有账号；
- 不同协议版本由网关的独立运行进程承载，测试版本不会替换当前内置运行包；
- 被节点使用的协议不能删除；
- 当前内置协议为 `Baileys Web协议 · 6.7.24`。
