## 页面用途

首页是登录后的运行概览，用于快速判断账号池和营销任务是否处于正常状态，再跳转到对应菜单处理。它是汇总入口，不是资源配置页面。

## 主要内容

- 账号总量、在线或可用状态等账号池概况；
- 群发任务的当前状态和处理进度；
- 近期运行信息，以及指向账号管理或任务页面的快捷入口；
- 手动刷新，用于重新获取当前汇总数据。

## 状态理解

首页数据来自账号与超链任务的当前快照。任务执行中、等待账号、暂停、完成或失败时，会在概览中显示对应状态。首页适合发现问题，但具体目标的失败原因应进入[超链任务](/hyperlink/tasks)明细查看。

## 功能边界

- 首页不创建或编辑账号、渠道、模板和任务；
- 首页不替代账号统计或渠道统计，历史趋势应到相应数据页面查看；
- 刷新只重新读取数据，不会启动、暂停或重试任何任务。

## 推荐使用方式

1. 登录后先查看账号池与任务是否存在异常状态。
2. 发现账号异常时进入“资源 / 账号中心 / 账号管理”。
3. 发现任务等待或失败时进入“营销 / 超链营销 / 超链任务”。
4. 需要长期趋势或转化指标时进入对应统计菜单。
