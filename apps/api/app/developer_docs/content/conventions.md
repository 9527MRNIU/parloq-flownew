## 登录与权限

所有开发文档内容都从受保护的管理接口读取，未登录请求会被拒绝。登录后仍会受到角色权限约束：

- **菜单权限**决定页面是否出现在导航中，以及能否读取对应资源；
- **操作权限**决定是否可以新建、编辑、启停、导入、导出或购买；
- 管理员拥有系统管理能力，普通角色只获得明确分配的范围。

看到页面但看不到操作按钮，通常表示当前角色只有读取权限。

## 系统 ID

所有 Parloq 实体的主键和关联 ID 都是十进制 Snowflake 字符串。复制、导入、调用接口或保存选择值时必须按字符串处理，不能转换为 JavaScript `Number`，否则可能丢失精度。

| 场景 | 正确做法 | 错误做法 |
| --- | --- | --- |
| JSON | `"id": "5550780304068608"` | `"id": 5550780304068608` |
| 前端状态 | 保持 `string` | 使用 `parseInt` 或 `Number` |
| 路由参数 | 直接使用十进制字符串 | 自行添加业务前缀 |

旧客户端可能保留兼容标识，但页面显示和新接口关联都以 canonical `id` 为准。

## 手机号显示

存储和协议处理可以使用 E.164 形式，但所有用户可见手机号都不显示前导 `+`。例如页面显示 `8613800000000`，而不是 `+8613800000000`。

导入号码时可以包含空格、括号或短横线，页面会做基础清理；仍应确保国家码和号码本身正确。

## 启用、停用与归档

- **启用 / 停用**通常保留记录和历史引用，只改变它能否继续参与新任务或新分配。
- **归档**把记录移出当前工作列表，主要用于不再使用但仍需保留审计关系的数据。
- 有其他资源引用时，系统可能拒绝归档；应先解除引用，或者仅停用该资源。
- 界面中的“删除”在多数业务资源上表示业务归档，不等同于物理删除数据库记录。

## 状态与时间

列表状态描述当前业务阶段，不应只凭颜色判断。把鼠标移到状态标识上可查看原因、关联数据和异常说明。时间统一由管理端按当前显示规则格式化；导出数据时以文件内的明确字段为准。
