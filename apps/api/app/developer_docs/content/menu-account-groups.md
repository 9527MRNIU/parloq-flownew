## 页面用途

账号分组用于按国家、客户、业务用途或运营规则组织统一账号池。推广渠道和超链任务通过分组选择账号范围。

## 列表字段

- 分组名称和系统 ID；
- 分组说明；
- 当前账号数量；
- 创建时间。

## 可执行操作

- 新建分组；
- 编辑名称和说明；
- 删除不再使用的分组；
- 在账号管理中把单个或多个账号移入、改组或移出分组。

## 功能边界

- 分组只负责组织和调度范围，不改变账号凭据、连接状态、协议节点或 IP 绑定；
- 同一账号当前只属于一个账号分组；
- 已被渠道或任务引用的分组可能无法删除，应先处理引用关系；
- 任务启动后会按分组动态占用账号，分组本身不设置并发和发送速率。

## 推荐方式

让分组名称表达稳定的运营边界，例如“美国推广账号”或“客户 A 发送池”。短期任务节奏应放在超链策略中，不要通过频繁改名表达。
