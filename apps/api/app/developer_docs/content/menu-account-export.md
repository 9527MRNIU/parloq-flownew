## 页面用途

账号导出用于把满足条件的账号凭据生成可下载文件，支持单个或批量导出，主要用于迁移、受控备份和兼容已有工具。

## 导出格式

- **兼容 JSON**：生成 Baileys 凭据兼容结构，适合与既有导入流程配合；
- **完整备份**：保留系统支持的完整原生凭据结构，适合受控恢复场景；
- **批量导出包**：对当前选中的可导出账号生成归档包。

## 导出条件

列表会显示账号来源、分组、入库时间和是否满足导出条件。账号必须拥有可用且完整的凭据；未完成接入、已解绑或凭据缺失的账号不能导出。

## 安全要求

导出文件包含敏感登录凭据。下载后应进入受控存储，不要发送到群聊、工单正文或普通网盘。导出完成不会自动删除服务器端账号，也不会断开当前连接。

## 功能边界

- 导出不等于注销、迁移完成或切换当前运行节点；
- 兼容 JSON 只保证当前系统定义的兼容格式，不承诺任意第三方版本都可直接使用；
- 页面不会显示凭据原文，只有明确导出动作才生成下载文件；
- 批量导出会跳过或拒绝不满足条件的账号，不应把文件数量当作选择数量。
