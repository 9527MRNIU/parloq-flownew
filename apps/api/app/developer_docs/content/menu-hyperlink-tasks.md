## 页面用途

超链任务把消息模板、发送策略、目标数据包和发送账号分组冻结成一次可执行的群发任务，并持续展示下发与消息结果。

## 创建条件

创建任务时必须选择：

1. **超链模板**：本次发送的正文、媒体和按钮快照；
2. **发送策略**：并发账号数、节奏、重试和换号规则；
3. **目标数据包**：任务启动时生成目标执行记录；
4. **发送账号分组**：从组内动态占用可用账号，而不是永久写死账号列表。

## 任务状态

| 状态 | 说明 |
| --- | --- |
| 草稿 | 可编辑，可启动或取消 |
| 执行中 | 正在分配账号并提交消息 |
| 等待可用账号 | 当前分组没有可补位账号，按策略等待 |
| 已暂停 | 不再继续提交，可编辑后恢复 |
| 已完成 | 所有目标已进入终态 |
| 失败 | 任务级执行失败 |
| 已取消 | 不再处理剩余目标 |

## 任务统计与明细

列表区分“下发统计”和“发送统计”。下发统计包含等待、提交中、成功受理和失败；发送统计包含发送、送达和失败。成功受理只表示网关接受了发送请求，不等于对方已经送达或阅读。

任务明细按目标号码展示执行状态、消息状态、发送账号、尝试次数、最近更新时间和异常信息。用户可见号码不显示前导 `+`。

## 可执行操作

- 草稿或暂停状态下编辑；
- 启动草稿，或继续已暂停任务；
- 暂停执行中或等待账号的任务；
- 取消未结束任务；
- 查看分页目标明细；
- 删除不再需要的任务。

## 功能边界

- 修改模板、策略或数据包不会追溯改变已经启动任务的快照；
- 任务使用账号分组动态补位，不能在此页手工指定某一个固定账号；
- 暂停和取消只影响后续处理，已经受理的消息不能从接收端撤回；
- 运行中或等待账号的任务不能删除；删除其他任务会同时删除其本地执行明细；
- 页面不负责创建账号或修复账号连接，应到账号管理处理。
