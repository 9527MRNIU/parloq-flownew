## 页面用途

素材中心统一保存消息模板可复用的文本、图片、视频、语音、名片、文件、GIF 和贴纸。素材可以独立预览、下载、启停或删除。

## 素材类型与限制

| 类型 | 支持范围 | 大小上限 |
| --- | --- | ---: |
| 图片 | JPEG、PNG、WebP、AVIF | 8 MB |
| 视频 | MP4、MOV、WebM | 64 MB |
| 语音 | MP3、M4A、OGG、WAV、FLAC | 16 MB |
| 文件 | PDF、Office、TXT、CSV、ZIP 等 | 64 MB |
| GIF | GIF | 16 MB |
| 贴纸 | WebP | 1 MB |

文本素材按正文、页头、页脚、按钮四种角色约束长度，分别为 4096、60、60、25 个字符。名片包含联系人名称和不带前导 `+` 的手机号。

## 可执行操作

- 按素材类型、状态和文本角色筛选；
- 单个或批量上传二进制素材，并选择命名方式；
- 创建原文 / 译文文本和名片素材；
- 预览、下载和编辑；
- 批量启用、停用、删除或修改文本角色；
- 查看文件是否缺失、类型、大小和更新时间。

## 功能边界

- 素材中心不负责选择收件人或直接发送消息；
- 停用素材会阻止新模板选择，但已启动任务仍使用自己的快照；
- 被模板引用的素材不能删除；未被引用的素材删除后无法恢复；
- 文件通过扩展名、MIME 和大小校验不代表内容业务正确；
- 文本译文是素材字段，不会自动调用翻译服务。
