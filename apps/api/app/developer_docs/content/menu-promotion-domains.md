## 页面用途

域名管理负责购买域名并接入推广系统，同时确认 DNS、TLS 和托管状态是否满足渠道使用条件。接入已有域名的页面入口目前不开放。

## 域名状态

| 状态 | 含义 |
| --- | --- |
| DNS | 域名解析是否指向系统要求的目标 |
| TLS | HTTPS 证书是否可用 |
| 就绪状态 | DNS、TLS 和托管条件是否全部满足 |
| 绑定渠道 | 当前引用该域名的渠道数量 |
| 最近验证 | 最近一次主动或系统验证时间 |

只有 `channelSelectable` 就绪的域名才可在渠道配置中选择。

## 购买域名

拥有购买权限的用户可以询价、选择年限和自动续费选项并创建订单。订单会经历待支付、已支付、开通中、结果待确认、完成、取消或失败等状态。订单完成并生成域名记录后，系统会在后台自动推进 Cloudflare、NameSilo、宝塔和公网验证，无需反复点击继续。

宝塔策略可在购买域名前设置。系统会在宝塔连接测试或打开策略时检测 Nginx 防火墙插件，并默认启用 CDN 模式、关闭 CC 防御、启用中国地区拦截。没有安装插件的服务器会跳过该策略，不会中断域名接入。

## 可执行操作

- 编辑启用状态；
- 立即验证 DNS 与 TLS；
- 对可购买域名询价并创建订单；
- 配置可选的宝塔 Nginx 防火墙接入策略；
- 刷新 NameSilo 域名列表时，自动确认账户已持有的异常系统订单并继续接入；
- 删除不再使用的本地域名记录。

## 功能边界

- 保存域名不代表解析和证书已经完成；
- 域名可用不代表渠道已经发布，还需在渠道内绑定短码和模板；
- 已被渠道或推广集成引用的域名应先解除绑定，再删除；
- 删除只影响本系统记录，不会删除 NameSilo 注册、Cloudflare Zone、DNS 或宝塔站点；
- 只有系统购买并由平台托管的域名会自动在后台接入；已有外部域名仍保持手动管理。
