## 页面用途

域名管理负责把外部域名或平台购买域名接入推广系统，并确认 DNS、TLS 和托管状态是否满足渠道使用条件。

## 域名状态

| 状态 | 含义 |
| --- | --- |
| DNS | 域名解析是否指向系统要求的目标 |
| TLS | HTTPS 证书是否可用 |
| 就绪状态 | DNS、TLS 和托管条件是否全部满足 |
| 绑定渠道 | 当前引用该域名的渠道数量 |
| 最近验证 | 最近一次主动或系统验证时间 |

只有 `channelSelectable` 就绪的域名才可在渠道配置中选择。

## 接入已有域名

录入域名时不要包含 `http://`、`https://` 或结尾斜杠。保存后按照页面给出的 CNAME / TXT 信息完成解析，再执行“立即验证”。外部接入域名默认由客户自行管理 DNS。

## 购买域名

拥有购买权限的用户可以询价、选择年限和自动续费选项并创建订单。订单会经历待支付、已支付、开通中、结果待确认、完成、取消或失败等状态。只有订单完成并生成域名记录后，才进入解析和证书验证阶段。

## 可执行操作

- 接入已有域名；
- 编辑启用状态；
- 立即验证 DNS 与 TLS；
- 对可购买域名询价并创建订单；
- 对待确认订单执行对账，或在允许时取消订单；
- 删除不再使用的本地域名记录。

## 功能边界

- 保存域名不代表解析和证书已经完成；
- 域名可用不代表渠道已经发布，还需在渠道内绑定短码和模板；
- 已被渠道或推广集成引用的域名应先解除绑定，再删除；
- 删除只影响本系统记录，不会删除 NameSilo 注册、Cloudflare Zone、DNS 或宝塔站点；
- 页面不会接管外部注册商账号，外部域名的续费仍由原注册商负责。
