## 页面用途

超链模板用于组合一条可复用消息的页头、正文、页脚、媒体素材和交互按钮。任务启动时会保存模板快照，因此后续编辑不影响已启动任务。

## 消息结构

### 页头

页头可以为空，也可以选择图片、视频或文档素材。页面会按素材类型筛选可选项。

### 正文与页脚

正文是必填内容，可使用系统支持的格式化工具和变量占位符。页脚为可选辅助文案。文本可以直接输入，也可以从素材库选择符合角色的文本素材。

### 按钮

一条模板最多配置 3 个按钮，并受各类型上限约束：

| 类型 | 单模板上限 | 用途 |
| --- | ---: | --- |
| 自定义 / 快速回复 | 3 | 返回预定义选择 |
| 访问网站 | 2 | 打开 URL |
| 拨打电话号码 | 1 | 发起电话动作 |
| 复制内容 | 1 | 复制指定文本 |
| 单选菜单 | 1 | 展示一组选项 |

## 可执行操作

- 按名称、状态和页头类型筛选；
- 创建或编辑消息结构；
- 实时预览组合效果；
- 启用或停用模板；
- 复制现有模板后再修改；
- 归档不再使用的模板。

## 功能边界

- 本页面的“模板”是群发消息模板，不是推广落地页 ZIP 模板；
- 选择素材只保存关联与发送快照，不会修改素材库原文件；
- 模板本身不选择收件人、账号分组或发送策略；
- 已停用模板不会用于新任务，历史任务仍保留自己的内容快照。
