## 页面用途

渠道统计按日期和渠道聚合推广访问、号码提交、登录 / 配对成功和广告成本，适合比较渠道转化效率并导出当前结果。

## 筛选范围

可以按日期、渠道、创建人、模板和目标国家筛选，也可以选择是否显示裂变数据、模板和创建人列。单次查询的日期跨度最多 366 天。

## 指标定义

| 指标 | 定义 |
| --- | --- |
| 登录请求次数 | `phone_submit` 原始提交事件数 |
| 登录请求人数 | 同一渠道内按线索去重的提交人数 |
| 登录成功次数 | 登录成功与配对成功终态事件次数 |
| 登录成功人数 | 同一渠道内按访客去重的成功人数 |
| 请求登录率 | 登录请求人数 ÷ 独立访客 |
| 登录成功率 | 登录成功人数 ÷ 登录请求人数 |
| 访客上号率 | 登录成功人数 ÷ 独立访客 |
| 获号成本 | 广告消耗 ÷ 登录成功人数 |

裂变访问通过 `trafficSource=fission` 单独聚合，不混入直推漏斗。

## 每日广告数据

展开渠道行可以查看每日花费、展示、点击及相关成本字段。拥有 `promotion.statistics.manage` 权限时，修改后的值会自动保存；只读用户只能查看。

## 可执行操作

- 应用或重置筛选条件；
- 刷新当前统计；
- 展开每日明细并维护广告指标；
- 导出当前筛选结果为 CSV。

## 功能边界

- 统计只反映已采集事件和已录入广告数据；缺失的广告花费不会自动推算；
- 导出只包含当前筛选后的渠道行和可见业务字段；
- 统计页面不修改渠道配置，也不影响正在运行的落地页。
