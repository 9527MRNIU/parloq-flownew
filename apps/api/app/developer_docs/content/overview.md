## 文档范围

开发文档用于说明 Parloq 管理端已经上线的菜单能力，以及推广模板接入系统时必须遵守的技术约定。第一版覆盖 23 个可操作菜单页面，并提供一套独立的模板开发章节。

文档内容以当前系统代码、页面字段和接口行为为准。尚未形成实际操作能力的入口不会作为功能说明收录。

## 两类内容

### 菜单功能说明

菜单文档与管理端导航保持一致。每一页都会说明：

- 页面解决什么问题，以及适合由谁使用；
- 页面展示的字段、指标和状态代表什么；
- 新建、编辑、启停、删除等操作会产生什么结果；
- 页面明确不负责什么，避免把相邻能力混在一起；
- 使用前依赖哪些资源或权限。

### 模板开发规范

模板开发章节面向落地页设计和开发人员，说明当前唯一支持的 `promotion-template/v3` 自包含包格式、`PromotionBridge` 运行时、白标组件、多语言方式和验收标准。

## 如何阅读

如果你在使用后台，建议先在左侧找到同名菜单页面，再查看“功能边界”和“标准操作流程”。如果你在开发推广模板，请从“模板开发 / 开发流程”开始，并以 v3 章节为准。

> 页面中的权限标识用于解释访问边界，不代表可以在浏览器中绕过系统权限。最终是否可见、是否可操作，均由当前登录用户所属角色决定。

## 文档维护原则

1. 功能先上线，文档再声明其可用边界；文档不能提前承诺未实现能力。
2. 菜单字段、状态或接口契约发生变化时，同一版本应同步更新对应页面。
3. 系统内部实现细节只有在影响使用者决策时才进入文档。
4. 账号凭据、代理密码、访问令牌等敏感信息不进入示例。
