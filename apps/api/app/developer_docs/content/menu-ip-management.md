## 页面用途

IP 管理维护 HTTP、HTTPS 和 SOCKS5 代理，提供健康检测、账号固定绑定和全局首次分配策略。此页面属于管理员运营能力。

## 代理字段

- 名称、协议、主机和端口；
- 国家 / 地区和供应商；
- 用户名、密码的掩码状态；
- 当前健康结果和最近检测信息；
- 已绑定账号数量及容量；
- 启用状态。

代理密码会加密保存，页面和读取接口不会返回原始密码。

## 可执行操作

- 单个编辑或按行批量添加代理；
- 对代理执行健康检测；
- 启用、停用或归档；
- 查看代理的账号绑定；
- 手工绑定或解绑账号；
- 配置全局账号 IP 分配策略。

## 分配策略

| 配置 | 说明 |
| --- | --- |
| 严格 1:1 | 每个代理最多绑定一个账号 |
| 租户内复用 | 同一租户可在容量内复用代理 |
| 低负载优先 | 优先选择当前绑定较少的代理 |
| 仅手动分配 | 系统不自动选择代理 |
| 国家匹配 | 严格、优先或关闭账号国家匹配 |
| 避开异常 IP | 自动分配时排除异常或停用代理 |
| 保持固定绑定 | 分配成功后持续使用同一代理，直到手工解绑 |

## 功能边界

- 健康检测只证明检测时网络可达，不保证之后持续稳定；
- 解绑账号不会删除代理，也不会自动选择新代理，后续行为取决于分配策略；
- 修改全局策略主要影响之后的自动分配，不批量重排已有固定绑定；
- 归档前应先处理仍在使用的账号绑定。
