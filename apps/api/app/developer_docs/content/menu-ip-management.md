## 页面用途

代理管理维护 HTTP、HTTPS 和 SOCKS5 代理，提供健康检测、账号固定绑定和全局首次分配策略。此页面属于管理员运营能力。

## 代理字段

- 协议、主机和端口；
- 国家 / 地区和供应商；
- 用户名、密码的掩码状态；
- 当前健康结果、冷却时间和最近检测信息；
- 已绑定账号数量及容量；
- 启用状态。

代理密码会加密保存，页面和读取接口不会返回原始密码。

## 可执行操作

- 按行检测代理的首次 WhatsApp 可达性和出口国家，再选择只导入健康代理或导入全部有效代理；
- 对代理执行手动复检；
- 启用、停用或删除；
- 查看代理的账号绑定；
- 手工绑定或解绑账号；
- 配置全局账号 IP 分配策略。

## 分配策略

| 配置 | 说明 |
| --- | --- |
| 严格 1:1 | 每个代理最多绑定一个账号 |
| 租户内复用 | 同一租户可在容量内复用代理 |
| 低负载优先 | 优先选择当前绑定较少的代理 |
| 仅手动分配 | 系统不自动选择代理 |
| 国家匹配 | 选择按访问国家或号码国家优先匹配；没有访问国家时回退号码国家 |
| 连续失败次数 | 网关实际使用连续失败达到阈值后进入冷却；认证失败立即隔离 |
| 冷却时间 | 冷却期间代理不参与任何自动分配，到期后以低优先级试用 |
| 保持固定绑定 | 分配成功后持续使用同一代理，直到手工解绑 |

## 功能边界

- 首次检测阶段不写入数据库，管理员确认导入范围后才创建代理；
- 系统不做定时轮询；首次检测并导入后，状态主要由网关真实配对、连接和重连结果回写；
- 检测会携带真实协议和凭证访问 WhatsApp Web，不再只检查 TCP 端口；
- 已绑定账号不会因代理异常自动更换固定代理；代理进入冷却时账号会断开并保留会话，发送任务可切换其他健康账号；
- 解绑账号不会删除代理，也不会自动选择新代理，后续行为取决于分配策略；
- 修改全局策略主要影响之后的自动分配，不批量重排已有固定绑定；
- 删除前应先处理仍在使用的账号绑定；删除后本系统记录无法恢复。
