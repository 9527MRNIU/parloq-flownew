## 页面用途

节点管理维护协议定义的运营实例。一个协议可以创建多个节点，每个节点分别设置进号、营销、容量、连接和同步策略。

## 节点开关

- **进号开关**：关闭后停止新账号通过该节点接入，不影响已在线账号；
- **营销开关**：关闭后节点内账号不再被营销任务选择；
- **批量上线 / 下线**：对选中节点统一调整在线运行状态。

## 容量与连接策略

节点可以设置账号总量、在线账号和并发配对上限。留空表示不限制。连接模式支持“按需在线”和“持续连接”；按需在线空闲后只断开 Socket，不退出登录。

公共配对风控分别使用设备指纹、来源 IP、号码和渠道作为限速维度。资料同步范围在接入开始时保存快照，之后修改不会改变进行中的接入。

## 功能边界

- 节点必须绑定一条已构建完成且启用的协议；
- 已有账号的节点不能直接切换协议；
- 修改节点不会自动迁移历史账号；
- 被账号、渠道或路由策略引用的节点不能删除。
