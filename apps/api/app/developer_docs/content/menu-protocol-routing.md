## 页面用途

路由策略单独维护渠道使用的协议池和节点回退顺序，不再与协议节点设置混排。只有渠道明确绑定路由策略时才会按照成员顺序回退；直接绑定协议节点的渠道永不自动切换。

## 回退规则

每个路由策略保存一组有顺序的协议节点。渠道发起新接入时，系统选择第一个当前可接入且未超容量的成员；如果没有可用成员，请求会明确失败，不会绕过配置使用其他节点。

勾选协议节点的先后顺序就是回退优先级。调整顺序时需要按目标顺序重新选择成员。

## 功能边界

- 路由策略只影响之后发起的新接入，不迁移历史账号；
- 被推广渠道使用的路由策略不能删除；
- 协议节点的容量、开关、连接和同步配置仍在“节点管理”维护；
- 删除或停用成员不会自动为直接绑定节点的渠道启用回退。
