## 页面用途

直接短链通过已配置的 Bitly 账号创建真实短链接，并保留目标地址、服务账号和点击数。访问链路是“Bitly 短链 → 原始目标地址”，不使用 Parloq 推广域名。

## 创建短链

填写目标地址和可选内部标题。管理员可以指定某个可用 Bitly 账号，普通用户由系统自动选择可用账号。创建成功后列表展示短链接、目标地址、账号、点击数和创建时间。

## Bitly 账号

管理员可以维护账号名称、访问令牌、Group GUID、短域名和启用状态。访问令牌保存后只返回掩码，不会在页面重新显示原文。

账号停用或归档后不再用于创建新短链，但不会自动删除已经在 Bitly 上创建的链接。

## 可执行操作

- 按标题、短链接或目标地址搜索；
- 按 Bitly 账号筛选；
- 创建和编辑直接短链；
- 打开或复制短链接；
- 查看点击数；
- 归档短链或管理员账号。

## 功能边界

- 本页不生成本站域名的中转短链；
- 点击统计取决于 Bitly 返回的数据，不等同于推广落地页的号码提交或成功转化；
- 归档是停止在当前列表中使用，不保证第三方地址立即失效；
- Bitly 凭据属于敏感配置，不应复制到文档、日志或普通用户界面。
