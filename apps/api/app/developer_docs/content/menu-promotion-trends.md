## 页面用途

趋势图表按天展示独立访客、号码提交和登录 / 配对成功，用于观察某个渠道或全部渠道在所选日期范围内的转化变化。

## 图表组成

- **访问转化漏斗**：独立访客 → 号码提交 → 登录 / 配对成功；
- **转化率趋势**：按天展示号码请求率和请求成功率；
- **每日明细表**：列出每一天的访客、提交、成功人数和对应转化率。

## 筛选与操作

选择开始日期、结束日期和渠道后点击“查询”。“刷新”重新读取当前条件，“重置”恢复默认日期和全部渠道。

指标去重逻辑与[渠道统计](/promotion/statistics)一致：提交按渠道和线索去重，成功按渠道和访客终态去重。

## 功能边界

- 趋势图表不录入广告成本，也不展示单个线索明细；
- 图表为空时表示所选范围没有对应事件，不等于渠道配置异常；
- 该页面用于观察趋势，不负责启停渠道或修改模板。
