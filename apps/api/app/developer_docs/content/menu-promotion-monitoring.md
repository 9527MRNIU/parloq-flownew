# 访问监控

访问监控按真实记录逐条展示推广链路中的客户端行为、服务端业务动作和集成回传。每条记录直接使用服务端生成的 Snowflake ID，不创建额外的访问 ID，也不会把多条记录拼成一条访问时间线。

## 记录来源

- 客户端行为：页面访问、离开页面和页面保护触发等由落地页运行脚本上报的行为；
- 服务端业务：提交号码、配对检查、生成配对码、失败和成功等由应用服务端产生的记录；
- 集成回传：模板集成运行时向平台回传的声明事件和附加数据。

“提交号码”在配对接口接受有效请求时由服务端记录，发生时间使用服务端时间。客户端上报接口不接受 `phone_submit`。

## 列表筛选

可按日期、记录来源、事件类型、流量来源、访问国家、渠道和模板筛选，也可搜索记录 ID、访客 ID、访问 IP、事件、渠道、模板或域名。默认查询最近 7 天，单次最多查询 90 天。

列表中的记录 ID 是数据库事件本身的 Snowflake ID。访客 ID 只用于识别 UV 和查询同一匿名访客，不作为记录的父级或聚合维度。

## 记录详情

详情只解释当前一条记录，包括事件、来源、服务端记录时间、落地页、渠道、模板、集成版本、设备、访问 IP、访问国家、网络采集来源、幂等标识及附加数据。账号中心的接入记录继续负责展示完整账号接入流程、协议路由和资料同步状态。

## 数据边界

访问监控不是 Nginx 访问日志。页面 HTML 或资源请求到达 Nginx，但客户端脚本没有成功运行时，Nginx 可能有请求日志，而访问监控没有对应的客户端行为记录。

访问 IP 和访问国家由应用服务端从可信代理请求头中采集，客户端事件数据不能指定或覆盖。平台管理的推广域名优先使用 Cloudflare 提供的连接 IP 和国家；后续配对成功、失败等服务端事件继承最初配对请求的网络快照。原有渠道国家表示推广目标国家，不等同于访客实际所在国家。
