## 页面用途

账号管理是统一账号池的操作中心，用于查看账号来源、连接与校验状态、分组、代理、资料数据，并执行连接、同步和解绑等动作。

## 账号来源

账号可以通过推广落地页完成接入，也可以由有权限的用户导入兼容账号 JSON。两种来源最终都进入同一个账号池，并使用相同的系统 ID、分组和代理规则。

## 列表信息

| 区域 | 说明 |
| --- | --- |
| 账号 | 显示手机号、系统 ID 和当前综合状态 |
| 来源 | 落地页接入或 JSON 导入等来源 |
| 分组 | 当前业务分组，可单个或批量修改 |
| 代理 | 系统自动分配或管理员固定的隔离代理 |
| 账号数据 | 头像、群组、好友等已同步资料摘要 |

## 可执行操作

- 搜索、筛选并批量选择账号；
- 单个或批量修改账号分组；
- 导入账号 JSON，并可选择分组、协议和代理；
- 重新提交资料同步任务；
- 连接或断开账号 Socket；
- 发送测试消息；
- 登出并解绑设备；
- 管理账号的隔离代理。

## 连接状态边界

“断开”只断开当前连接，不等于从 WhatsApp 登出；之后可以重新连接。“登出并解绑设备”会清除会话能力，是更强的破坏性操作。资料同步在后台执行，提交成功不代表同步已经立即完成。

## 功能边界

- 页面不创建推广渠道或群发任务；
- 改组不会迁移账号协议节点或自动改变 IP；
- 固定代理受 IP 容量和健康策略约束；
- 测试消息只验证单账号发送链路，不代表批量任务策略和目标数据均正确；
- 导入凭据属于敏感操作，导入文件不应通过普通业务渠道传播。
