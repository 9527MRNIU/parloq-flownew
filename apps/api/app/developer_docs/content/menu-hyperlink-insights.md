## 页面用途

超链市场透视按“发送账号号码国家 × 接收号码国家”分析消息发送结果和账号风险，用于比较不同国家组合的送达表现与封禁风险。两个国家维度都由服务端根据 E.164 号码统一识别。

## 筛选条件

- 开始日期与结束日期；
- 发送账号号码国家；
- 接收号码国家。

国家选项来自当前结果集。首次加载后可继续缩小范围，点击刷新重新获取所选条件的数据。

## 核心指标

| 指标 | 说明 |
| --- | --- |
| 发送 | 已进入发送统计的消息数量 |
| 送达 | 已收到送达状态的数量 |
| 失败 | 当前组合下的失败数量 |
| 异常账号 | 发送期间被判定异常的账号数 |
| 封禁账号 | 被判定封禁的账号数 |
| 封禁率 | 封禁账号相对于账号总量的比例 |

页面同时提供国家组合矩阵和高风险组合排序，便于发现需要降量、换号或调整策略的区域。

## 功能边界

- 透视页只分析已经产生的发送和账号状态，不直接暂停任务或隔离账号；
- 封禁率用于运营判断，不是对某个国家或线路的长期承诺；
- 数据为空时应先确认日期范围内是否有实际任务与消息结果。
