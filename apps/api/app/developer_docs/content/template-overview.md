## 当前版本

新推广模板统一使用 `promotion-template/v2`。v1 仍可用于已有模板兼容，但不应作为新项目的起点。

v2 把职责分成两部分：模板负责视觉、文案、多语言和配对状态展示；平台负责渠道解析、协议路由、账号分组、公共接口鉴权、营销事件投递和交互保护。

## 推荐开发流程

1. 在“推广 / 模板管理 / 设计规范”下载 `account-link-elements/v1` 白标能力主题；
2. 基于能力主题修改布局、颜色、字体和品牌文案，不复制配对网络逻辑；
3. 准备 `manifest.json`、`index.html`、相对路径资源和多语言文件；
4. 本地完成多尺寸、RTL、失败态和重试态检查；
5. 打包 ZIP 并导入模板管理；
6. 使用管理端模拟预览检查设备和语言；
7. 绑定一个真实测试渠道，完成全状态验收后再用于正式渠道。

## 模板负责什么

- 页面布局、主题和品牌视觉；
- 手机号输入区域的呈现；
- 配对码、等待、重连、成功、失败、过期和取消状态 UI；
- 用户操作引导、应用启动按钮和手工步骤；
- 多语言文本、RTL 和无障碍体验。

## 平台负责什么

- 注入 `promotion-runtime-config` 和 `window.PromotionBridge`；
- 根据渠道选择域名、账号分组和协议节点 / 协议池；
- 创建接入尝试、保存状态令牌并校验权限；
- 为新账号分配代理并执行资料同步；
- 处理渠道配置的浏览器像素、CAPI 和事件去重；
- 执行页面检查保护和应用内浏览器策略。

## 关键边界

模板不得保存协议节点 ID、拼接网关地址、持久化用户手机号、构造状态鉴权头，或注入自己的第三方统计 SDK。一个模板必须可以绑定到使用不同协议路由的多个渠道，而无需修改模板包。
