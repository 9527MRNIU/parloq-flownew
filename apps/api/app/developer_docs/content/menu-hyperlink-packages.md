## 页面用途

数据包保存超链任务的目标号码和可选国家代码，是任务目标范围的可复用资源。

## 导入格式

新建数据包时可以直接粘贴内容，也可以读取 `.txt` 或 `.csv` 文件。每行一个号码，可在逗号后附国家代码：

```text
8613800000000,CN
15550000000,US
```

首行如果是 `phone`、`number`、`mobile`、`手机号` 等常见表头会被忽略。页面会移除号码中的前导 `+` 和常见分隔字符，但不会替你判断号码是否真实存在。

## 列表字段

- **号码数**：当前版本中包含的目标数量；
- **当前版本**：数据发生变更后的修订号；
- **使用任务**：引用该数据包的任务数量；
- **状态**：资源是否可用于新任务。

## 可执行操作

- 导入新数据包；
- 编辑名称和未冻结的号码内容；
- 查看版本、使用情况和更新时间；
- 删除不再用于新任务的数据包。

## 功能边界

- 数据包只定义目标，不定义消息内容、账号来源或发送节奏；
- 已启动任务使用启动时冻结的目标记录，之后修改数据包不会改变该任务；
- 国家代码是运营维度和格式辅助，不代替完整的号码有效性验证；
- 被任务引用的数据包不能删除；未被引用的数据包删除后会同时删除其目标号码。
