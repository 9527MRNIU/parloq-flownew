## 页面用途

账号统计从统一账号池生成日快照、国家分布和账号质量视图，用于观察账号规模、在线状况和资料完整度。

## 查询条件

可以选择日期范围和国家，也可以使用快捷日期按钮。刷新会重新计算当前条件下的汇总和明细。

## 统计区块

### 日统计

按天展示账号池规模、在线数、新增账号、解绑阶段和净变化，适合判断资源池是否持续增长或出现集中流失。

### 国家统计

按账号国家展示账号数、在线数和有效率。国家信息依赖账号资料同步；未完成同步的账号可能无法进入明确国家分组。

### 账号质量

列出账号来源、头像、群组、好友、双向关系和质量评分。评分是资料维度的运营参考，不代表平台对账号未来稳定性的保证。

## 功能边界

- 本页只读取统计，不连接、断开或修改账号；
- 国家和质量数据依赖协议节点配置的资料同步范围；
- 日快照反映采集时状态，不能替代账号管理中的实时连接状态；
- 需要处理具体账号时，应进入[账号管理](/resources/accounts/manage)。
