## 页面用途

超链策略定义任务如何占用账号、控制单账号发送节奏，以及遇到失败或账号不足时如何处理。

## 策略字段

| 字段 | 作用 |
| --- | --- |
| 单账号峰值 QPS | 每个账号每秒最多提交的消息数 |
| 并发账号数 | 一个任务同时占用的账号槽位数量 |
| 失败重试次数 | 单个目标失败后的最大重试次数 |
| 重试间隔 | 两次尝试之间的基础等待秒数 |
| 连续失败换号阈值 | 同一账号连续失败到阈值后释放并补位 |
| 异常账号冷却 | 被换下账号暂不参与发送的秒数 |
| 没有可用账号时 | 等待并自动继续，或暂停整个任务 |
| 发送随机延迟 | 在发送节奏上增加毫秒级随机间隔 |

每个并发槽位会持续使用同一账号，只有账号异常、释放或出现空槽时才从任务绑定的账号分组补入新账号。

## 可执行操作

- 创建或编辑策略；
- 启用 / 停用策略；
- 查看账号槽位、节奏、重试和账号不足处理摘要；
- 删除不再用于新任务的策略。

## 功能边界

- 策略不能突破协议节点容量、账号状态或账号分组范围；
- QPS 是提交节奏上限，不承诺接收端的送达速度；
- 重试只针对系统判定可再次尝试的失败，不保证最终成功；
- 修改策略不追溯改变已经启动任务的策略快照。
- 被任务引用的策略不能删除；未被引用的策略删除后无法恢复。
