## 页面用途

菜单管理用于调整内置导航项的显示名称、排序、启用和可见状态，并查看路由路径与权限标识。该页面只对管理员开放。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 菜单名称 | 用户在导航中看到的名称 |
| 上级菜单 | 目录层级关系 |
| 类型 | 目录或页面 |
| 路由路径 | 前端页面地址；目录通常为空 |
| 权限标识 | 角色与接口读取权限使用的稳定标识 |
| 显示 | 是否出现在导航中 |

## 可编辑内容

当前页面允许修改名称、排序、启用状态和导航显示状态。内置菜单的路由、类型和权限标识只读，避免把现有页面指向错误权限。

- **停用**：菜单不再作为可访问入口；
- **隐藏**：保留路由和权限配置，但不在导航中显示；
- **排序**：控制同一层级菜单的相对顺序。

## 功能边界

- 菜单管理不会创建新的前端页面；没有实际路由的菜单配置不能凭空产生功能；
- 隐藏菜单不等于撤销角色权限，敏感功能应同时调整权限或停用；
- 修改权限标识需要代码和接口一起调整，因此不在普通编辑范围内；
- “开发文档”内容由系统版本提供，不在菜单管理页直接编辑。
